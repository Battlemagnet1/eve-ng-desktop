宿主机网络

pnet0 是 EVE 管理网，本工具永不修改。需要让实验里的设备上外网时， 有三种做法：① 拓扑里新建 Cloud0（型 pnet0）直连局域网； ② 用下面的 NAT 出口新建一条独立云，节点走 NAT 出去；③ 给 pnetN 绑物理网卡（需多网卡）。 pnet0 is the EVE management network, which this tool never modifies. To give lab devices internet access you have three options: 1) create a Cloud0 in the topology (type pnet0) that bridges to your LAN; 2) use the NAT uplink below to create a separate cloud and route nodes through NAT; 3) bind a physical NIC to pnetN (requires an extra NIC).

NAT 出口

在不改动 /etc/network/interfaces 的前提下，新建 pnetN 网桥 + dnsmasq + MASQUERADE，实验节点接上这条云即可访问外网。可一键卸载。 Without touching /etc/network/interfaces, this creates a pnetN bridge plus dnsmasq and MASQUERADE so lab nodes attached to that cloud can reach the internet. It can be removed in one click.
